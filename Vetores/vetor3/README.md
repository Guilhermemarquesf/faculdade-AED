# 📦 Exemplo de Tuplas em C#

Pequeno programa em **C#** para demonstrar o uso de **Tuplas**, mostrando como retornar múltiplos valores de uma única função e como manipular esses dados no código.

---

## 🚀 Tecnologias Utilizadas

* **Linguagem:** C# (.NET)
* **Conceitos aplicados:** 
  * Retorno de múltiplos valores usando Tuplas `(int, int, int)`
  * Desestruturação de tuplas `(x, y, z)`
  * Acesso a propriedades individuais (`Item1`)

---

## 💻 Como Executar o Projeto

1. Certifique-se de ter o [.NET SDK](https://dotnet.microsoft.com/) instalado.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto e execute:
   ```bash
   dotnet run
