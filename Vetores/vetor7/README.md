# 🔍 Verificador de Par ou Ímpar em C#

Programa desenvolvido em **C#** para receber um número inteiro do usuário, verificar se ele é par ou ímpar através de uma função booleana e exibir o resultado no console.

---

## 🚀 Tecnologias Utilizadas

* **Linguagem:** C# (.NET)
* **Conceitos aplicados:**
  * Uso de funções com retorno booleano (`true`/`false`)
  * Operador de módulo (`%`) para cálculo de resto de divisão
  * Estruturas condicionais (`if/else`)
  * Entrada e saída de dados no console

---

## 💻 Como Executar o Projeto

1. Certifique-se de ter o [.NET SDK](https://dotnet.microsoft.com/) instalado.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto e execute:
   ```bash
   dotnet run
