# 📊 Manipulação de Vetores e Funções Matemáticas em C#

Programa em **C#** desenvolvido para exercitar operações com arrays (vetores), lógica de percorrimento para encontrar valores extremos (maior e menor), cálculo de média e operações geométricas utilizando tuplas.

---

## 🚀 Tecnologias Utilizadas

* **Linguagem:** C# (.NET)
* **Conceitos aplicados:**
  * Declaração e manipulação de vetores (`int[]`)
  * Geração de números aleatórios (`Random`)
  * Funções com retorno de múltiplos valores via Tuplas `(double, double)`
  * Passagem de parâmetros por referência (`ref`)
  * Funções matemáticas da biblioteca `Math` (`Math.PI`, `Math.Pow`)

---
