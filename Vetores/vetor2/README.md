# 📉 Calculadora de Bhaskara em C#

Programa desenvolvido em **C#** para calcular o Delta e as raízes reais de uma equação do segundo grau ($ax^2 + bx + c = 0$) utilizando a fórmula de Bhaskara.

---

## 🚀 Tecnologias Utilizadas

* **Linguagem:** C# (.NET)
* **Conceitos aplicados:** 
  * Estruturas condicionais (`if/else`)
  * Funções matemáticas (`Math.Pow` e `Math.Sqrt`)
  * Passagem de parâmetros por referência (`out`)
  * Entrada e saída de dados no console

---

## 💻 Como Executar o Projeto

1. Certifique-se de ter o [.NET SDK](https://dotnet.microsoft.com/) instalado.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto e execute:
   ```bash
   dotnet run
