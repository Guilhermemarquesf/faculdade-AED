# 🧮 Calculadora de Fatorial em C#

Pequeno programa desenvolvido em **C#** para calcular o fatorial de um número inteiro informado pelo usuário, utilizando funções e estruturas de repetição.

---

## 🚀 Tecnologias Utilizadas

* **Linguagem:** C# (.NET)
* **Conceitos aplicados:** Lógica de programação, entrada e saída de dados (`Console`), laços de repetição (`for`) e criação de métodos.

---

## 💻 Como Executar o Projeto

1. Certifique-se de ter o [.NET SDK](https://dotnet.microsoft.com/) instalado na sua máquina.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto e execute o comando:
   ```bash
   dotnet run
