# 📈 Verificador de Maior Número em C#

Programa desenvolvido em **C#** para receber dois números inteiros do usuário, compará-los por meio de uma função lógica e exibir qual deles é o maior.

---

## 🚀 Tecnologias Utilizadas

* **Linguagem:** C# (.NET)
* **Conceitos aplicados:**
  * Criação e chamada de métodos com parâmetros e retorno
  * Estruturas condicionais (`if/else`) para tomada de decisão
  * Leitura e formatação de dados no console

---

## 💻 Como Executar o Projeto

1. Certifique-se de ter o [.NET SDK](https://dotnet.microsoft.com/) instalado.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto e execute:
   ```bash
   dotnet run
