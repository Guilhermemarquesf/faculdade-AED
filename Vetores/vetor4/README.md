# 🔢 Calculadora de Dobro em C#

Programa básico desenvolvido em **C#** para ler um número inteiro informado pelo usuário, calcular o seu dobro através de uma função e exibir o resultado no console.

---

## 🚀 Tecnologias Utilizadas

* **Linguagem:** C# (.NET)
* **Conceitos aplicados:** 
  * Entrada e saída de dados (`Console.ReadLine` / `Console.WriteLine`)
  * Conversão de tipos (`int.Parse`)
  * Criação e chamada de métodos com retorno

---

## 💻 Como Executar o Projeto

1. Certifique-se de ter o [.NET SDK](https://dotnet.microsoft.com/) instalado.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto e execute:
   ```bash
   dotnet run
