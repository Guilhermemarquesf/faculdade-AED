# 🔢 Calculadora de Triplo em C#

Programa básico desenvolvido em **C#** para ler um número inteiro fornecido pelo usuário, calcular o seu triplo por meio de uma função dedicada e exibir o resultado formatado no console.

---

## 🚀 Tecnologias Utilizadas

* **Linguagem:** C# (.NET)
* **Conceitos aplicados:**
  * Entrada e saída de dados (`Console.ReadLine` / `Console.WriteLine`)
  * Conversão de tipos de dados (`int.Parse`)
  * Criação, escopo e chamada de métodos com retorno

---

## 💻 Como Executar o Projeto

1. Certifique-se de ter o [.NET SDK](https://dotnet.microsoft.com/) instalado.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto e execute:
   ```bash
   dotnet run
