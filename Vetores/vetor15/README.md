# AchaMaior

Programa desenvolvido em **C#** com o objetivo de praticar a criação e utilização de **funções**.

## 📌 Sobre o projeto

O programa solicita ao usuário dois números inteiros e utiliza a função `AchaMaior` para comparar os valores e identificar qual deles é o maior.

A função recebe os dois números como parâmetros e retorna o maior valor encontrado.

## 🛠️ Tecnologias utilizadas

* C#
* .NET
* Console Application

## ⚙️ Funcionamento

1. O programa solicita o primeiro número.
2. O usuário informa o valor.
3. O programa solicita o segundo número.
4. O usuário informa o valor.
5. A função `AchaMaior` compara os dois números.
6. O maior número é retornado e exibido na tela.

## 💻 Exemplo

```text
Digite o primeiro numero:
10

Digite o segundo numero:
25

O resultado maior é: 25
```

## 🎯 Objetivo

Praticar conceitos básicos de **programação em C#**, principalmente:

* Declaração de variáveis;
* Entrada e saída de dados;
* Estruturas condicionais (`if`);
* Criação de funções;
* Passagem de parâmetros;
* Retorno de valores.
