# 📚 Faculdade - Algoritmos e Estruturas de Dados (AED)

Repositório destinado ao armazenamento de exercícios, algoritmos e projetos desenvolvidos durante a disciplina de **Algoritmos e Estruturas de Dados**.

> ⚠️ **Nota:** Este repositório está em constante desenvolvimento e novos tópicos, pastas e exercícios podem ser adicionados ao longo das aulas.

---

## 📁 Estrutura do Repositório

O projeto está organizado nas seguintes pastas de acordo com os conteúdos estudados:

* **`Recursividade/`**: Algoritmos e exercícios práticos focados em funções recursivas.
* **`Vetores/`**: Manipulação de vetores, matrizes e estruturas lineares de dados.
* **`Revision/`**: Exercícios de revisão e consolidação de conceitos fundamentais.
* **`WebBackEnd/`**: Implementações e integração de lógica com desenvolvimento Back-End.

---
